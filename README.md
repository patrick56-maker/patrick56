# PROJECT DESCRIPTION: PATRICK'S BISTRO WEBSITE

## Project Overview
Patrick's Bistro is a modern restaurant website designed to showcase the restaurant's food offerings, atmosphere, and services. The website provides visitors with an attractive and user-friendly platform to explore the restaurant's menu, learn about its story, and contact the restaurant.

## Technologies Used
- **HTML5:** Used to structure the website's pages and content.
- **CSS3:** Used to style the website, create layouts, and ensure responsiveness across different screen sizes.
- **JavaScript:** Used to implement interactive features such as mobile navigation and contact form validation.
- **CSS Grid and Flexbox:** Used to organize content and create responsive layouts.

## Implementation
The website was developed using Visual Studio Code. It consists of four main pages: Home, Menu, Our Story, and Contact. The Home page introduces the restaurant, the Menu page displays available food items, the Our Story page presents the restaurant's background, while the Contact page allows visitors to interact with the restaurant through a contact form.

The website features a modern blue, cream, and orange colour scheme, attractive food photography, and a responsive design that adapts to mobile and desktop screens.

## Conclusion
Patrick's Bistro demonstrates the application of fundamental web development technologies in creating an attractive, responsive, and interactive restaurant website. It provides a simple and accessible online presence for a restaurant business.
